# AfterGram для iOS

Неофициальный клиент Telegram для iPhone и iPad. Он сохраняет уже полученные сообщения, если собеседник удалит их.

![Telegram 13.0](https://img.shields.io/badge/Telegram-13.0-26A5E4)

AfterGram основан на Telegram iOS 13.0. Удалённое сообщение остаётся на прежнем месте в чате полупрозрачным, с корзиной и подписью «Удалено».

## Возможности

- Сохраняет полученные сообщения после удаления собеседником.
- Сохраняет фото, GIF, видео и видеосообщения, если файл успел загрузиться полностью.
- Хранит копии медиа отдельно от обычного кэша Telegram.
- Позволяет отключить функцию в **Настройки → Удалённые сообщения**.

AfterGram не может вернуть сообщения, которые устройство не получало, или медиа, которое не успело загрузиться и больше недоступно на сервере. Секретные чаты, запланированные сообщения и некоторые способы массовой очистки истории пока не поддерживаются. Сохранённые файлы занимают место; обычная очистка кэша их не удаляет.

## Скачать и установить

1. Скачай [последний опубликованный IPA](https://github.com/pipse363team/AfterGram-iOS/releases/download/latest/TelegramRetention.ipa) или открой [страницу релиза](https://github.com/pipse363team/AfterGram-iOS/releases/tag/latest). Файл называется **TelegramRetention.ipa**. Файл в релизе `latest` обновляется после успешного запуска workflow **Telegram 13.0 with retained messages** на ветке `main`.
2. Установи IPA через инструмент sideload-установки, который умеет подписывать приложения для iOS. Для бесплатной подписи Apple ID можно использовать [Sideloadly](https://sideloadly.io/) на Windows или macOS.
3. Подключи iPhone или iPad и следуй инструкциям выбранного установщика. Если iOS попросит, доверь сертификату в настройках устройства и включи режим разработчика.

IPA из релиза нужно подписать перед установкой: он не подписан твоим личным сертификатом. Бесплатная подпись Apple ID может требовать периодической переустановки. В этой сборке отключены расширения приложения и Apple Watch; доступность нативных push-уведомлений зависит от сертификата и профиля подписи.

## Уведомления через ntfy

Для текущего сервера AfterGram уведомления приходят в приложение [ntfy для iOS](https://apps.apple.com/app/ntfy/id1625396347). Настройка рассчитана на владельца сервера: нужен его закрытый API-токен. Не публикуй токен и имя темы.

1. Открой [страницу настройки уведомлений](https://pipse363team.github.io/AfterGram-iOS/webpush/) в Safari и введи HTTPS-адрес API своего сервера (обычно порт `9443`) и выданный владельцем API-токен. Страница сохраняет их в `localStorage` браузера на этом устройстве.
2. Установи ntfy. В ntfy открой **Settings → Default server** и укажи HTTPS-адрес ntfy своего сервера (обычно порт `9444`).
3. Вернись на страницу AfterGram, нажми **Получить настройки ntfy**. В ntfy нажми **+**, создай подписку и вставь только имя темы, которое показала страница.
4. Нажми на странице **Отправить тестовое уведомление**. Если оно пришло, уведомления настроены. Для перехода по реальному уведомлению iOS может сначала показать ntfy; результат зависит от версии приложения и настроек устройства.

Мост уведомлений учитывает mute-настройки Telegram. Содержание уведомления и ссылка для перехода обрабатываются личным сервером; ntfy.sh используется iOS-приложением ntfy как relay-сервис. Само приложение ntfy должно иметь разрешение на уведомления в iOS.

## Плагины

Плагины доступны в отдельной [сборке из GitHub Actions](https://github.com/pipse363team/AfterGram-iOS/actions/workflows/plugin-sdk.yml). Открой успешный запуск и скачай артефакт **AfterGram-13.0-plugins**.

В **Настройки → Плагины** можно импортировать `.plugin`, `.py` и исходные пакеты Elyx. Для поддерживаемых Android-вызовов есть действие **Подготовить для iOS**. Совместимость зависит от API конкретного плагина; Xposed и произвольные Android-экраны требуют переноса.

[Поддерживаемые возможности](docs/aftergram-plugins.md) · [Пример плагина](examples/plugins/aftergram_tools.plugin)

## Собрать самостоятельно

Сборку можно запустить через GitHub Actions — локальный Mac не обязателен.

1. Сделай форк репозитория.
2. Получи `api_id` и `api_hash` приложения на [my.telegram.org/apps](https://my.telegram.org/apps).
3. В **Settings → Secrets and variables → Actions** добавь секреты `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`.
4. В **Actions** выбери workflow **Telegram 13.0 with retained messages** и нажми **Run workflow**. Оставь тесты включёнными.
5. После успешного запуска скачай артефакт **TelegramRetention-13.0**. В нём будет IPA, который нужно подписать для установки.

Не добавляй API-значения в исходники или README.
