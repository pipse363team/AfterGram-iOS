# AfterGram for iOS

Telegram для iPhone и iPad, который сохраняет удалённые сообщения.

Если собеседник удалит сообщение, AfterGram оставит его на прежнем месте в чате. Оно станет полупрозрачным — 50% — а снизу появятся корзина и подпись «Удалено».

Основан на официальном клиенте Telegram iOS 13.0. Добавлено сохранение удалённых сообщений.

## Что умеет

- Сохраняет загруженные сообщения после удаления собеседником.
- Сохраняет фотографии, GIF, видео и видеосообщения, если файлы успели скачаться полностью.
- Хранит копии медиа отдельно от обычного кэша Telegram.
- Заранее загружает медиа сообщений, которые ты открываешь в чате.
- Позволяет выключить сохранение в **Настройки → Удалённые сообщения**.

**AfterGram выпускается только для iOS и iPadOS.** Это неофициальный клиент, не связанный с командой Telegram.

## Плагины

В **Настройки → Плагины** можно импортировать файлы `.plugin`, `.py` и исходные пакеты Elyx. Для поддерживаемых Android-вызовов появится кнопка **Подготовить для iOS**.

Есть нативные настройки и диалоги, работа с текстом и медиа, запросы Telegram API и фоновые задачи. Совместимость зависит от API конкретного плагина; Xposed и произвольные Android-экраны требуют переноса.

[Поддерживаемые возможности](docs/aftergram-plugins.md) · [Пример плагина](examples/plugins/aftergram_tools.plugin)

## Установка

1. Скачай **AfterGram-13.0.ipa** из [Releases](https://github.com/pipse363team/AfterGram-iOS/releases).
2. Подпиши IPA личным сертификатом через подходящий инструмент установки либо используй бесплатную подпись своим Apple ID через [Sideloadly](https://sideloadly.io/) на Windows или macOS.
3. Установи подписанный IPA на iPhone или iPad.
4. При необходимости разреши запуск приложения в настройках устройства и включи режим разработчика, если iOS его запросит.

IPA из релиза требует переподписи перед установкой. Расширения и приложение для Apple Watch в этой сборке отключены. Доступность push-уведомлений зависит от подписи и профиля установки.

## Как работает сохранение

Открой чат и дай медиа загрузиться. Если сообщение затем удалят с другого устройства, оно останется в локальной истории. Для просмотра удалённого видео или GIF нужна полная копия файла.

AfterGram не восстановит сообщения, которых клиент никогда не получал, и файлы, которые не успели скачаться и больше недоступны на сервере. Вся история всех чатов автоматически не загружается.

Сохранённые файлы занимают место и переживают обычную очистку кэша. Ручное удаление сообщения убирает его из чата, но пока не гарантирует удаление всех копий файла. Они удаляются вместе с данными аккаунта или приложения.

Секретные чаты, запланированные сообщения и некоторые способы массовой очистки истории пока не поддерживаются. Действия, которым нужен исходный объект сообщения на сервере, могут не работать после его удаления.

## Собрать самому

Mac не обязателен: сборку можно запустить через GitHub Actions, в том числе с Windows.

1. Сделай форк репозитория.
2. Получи свои **App api_id** и **App api_hash** на [my.telegram.org/apps](https://my.telegram.org/apps).
3. В **Settings → Secrets and variables → Actions** добавь секреты `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` с этими значениями.
4. В **Actions** выбери **Telegram 13.0 with retained messages** и нажми **Run workflow**. Оставь тесты включёнными.
5. После успешной сборки скачай **TelegramRetention-13.0** из **Artifacts**. Внутри — `TelegramRetention.ipa`, который нужно переподписать для установки.

Не добавляй значения API hash в исходники или README.

## Нашёл ошибку?

[Открой issue](https://github.com/pipse363team/AfterGram-iOS/issues) и напиши версию iOS, что делал и что получилось. Для проблем с сохранением укажи тип сообщения и успело ли медиа загрузиться. Скриншот или короткая запись экрана помогут разобраться.
